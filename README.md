# Context Architecture Vault — Starter System

এই ফোল্ডারটি যেকোনো নতুন সফটওয়্যার প্রজেক্ট শুরু করার জন্য একটি প্রস্তুত **Context Architecture Vault** টেমপ্লেট সিস্টেম। এর মূল উদ্দেশ্য হলো **Vibe Coding**-এর বিশৃঙ্খলা বন্ধ করে Antigravity এজেন্টকে **Step → Test → Pass → Next Step** লুপে নির্ভুলভাবে চালানো।

---

## ১. ফোল্ডারের কাঠামো
```text
context-architecture-vault/
├── AGENTS.md           # Master Router Hub & Execution Loop নিয়মাবলী
├── scaffold.ps1        # যেকোনো নতুন প্রজেক্টে ১ কমান্ডে Vault কপি করার স্ক্রিপ্ট
├── README.md           # ব্যবহার নির্দেশিকা
└── vault/
    ├── 01-PRD.md       # কী বানানো হবে ও কী বানানো হবে না (Out of Scope)
    ├── 02-STATE.md     # লাইভ চেকপয়েন্ট ট্র্যাকার ও অ্যাপের স্টেট মেশিন
    ├── 03-TOKENS.md    # কালার, ফন্ট, স্পেসিং ও সিস্টেম কনস্ট্যান্ট
    ├── 04-STACK.md     # অনুমোদিত ফ্রেমওয়ার্ক, নিষিদ্ধ লাইব্রেরি ও টেস্ট কমান্ড
    ├── 05-SCHEMA.md    # ডাটাবেস টেবিল, টাইপ ও API কন্ট্রাক্ট
    └── 06-PLAN.md      # Atomic Steps + প্রতি স্টেপের বাধ্যতামূলক Verification Gate
```

## ২. নতুন প্রজেক্টে ব্যবহার করার নিয়ম (৩টি ধাপ)

### ধাপ ১: নতুন প্রজেক্টে Vault কপি করা
PowerShell-এ এই স্ক্রিপ্টটি চালিয়ে যেকোনো নতুন ফোল্ডারে ভল্ট সেটআপ করুন:
```powershell
cd "e:\ai video editor\context-architecture-vault"
.\scaffold.ps1 -TargetDir "E:\projects\my-new-app"
```
*(চাইলে ম্যানুয়ালি `AGENTS.md` এবং `vault/` ফোল্ডার কপি করেও নতুন প্রজেক্টে নিতে পারেন।)*

### ধাপ ২: আইডিয়া থেকে Spec লক করা (কোড লেখার আগে)
নতুন প্রজেক্ট ফোল্ডারটি Antigravity-তে খুলে প্রথমে কোড লিখতে বলবেন না। বরং `/grill-me` বা `/plan` ব্যবহার করে বলুন:
> *"আমার আইডিয়া হলো [এখানে আইডিয়া লিখুন]। আগে কোনো কোড লিখবে না। প্রথমে প্রশ্ন করে পরিষ্কার হয়ে `vault/01-PRD.md` থেকে `vault/05-SCHEMA.md` পর্যন্ত ফাইলগুলো সম্পূর্ণ পূরণ করো, তারপর `vault/06-PLAN.md`-এ ছোট ছোট Atomic Step ও Verification Gate সাজিয়ে দেখাও।"*

### ধাপ ৩: স্বয়ংক্রিয় Step → Test → Next Step রান
ভল্ট ও `06-PLAN.md` আপনার পছন্দমতো লক হয়ে গেলে `/goal` কমান্ড দিয়ে বলুন:
> *"`AGENTS.md`-এর Autonomous Execution Loop মেনে `vault/06-PLAN.md`-এর প্রথম আনচেকড স্টেপ থেকে শুরু করে প্রতিটা স্টেপ কোড করো, Verification Gate টেস্ট রান করো, পাস হলে `02-STATE.md` ও `06-PLAN.md` আপডেট করে পরের স্টেপে এগিয়ে যাও।"*

## ৩. সিস্টেমটি কীভাবে এজেন্টকে নিয়ন্ত্রণ করে?
1. **একবারে মাত্র ১টি স্টেপ:** `AGENTS.md` এজেন্টকে `Step N+1`-এর কোড আগেই লিখতে নিষেধ করে।
2. **পাস ছাড়া সামনে যাওয়া নিষিদ্ধ:** `Verification Gate` (যেমন `tsc --noEmit`, `npm test`, `pytest`) এক্সিট কোড `0` না দিলে পরের স্টেপ শুরু করতে পারে না।
3. **লাইভ রিজিউম:** সেশন শেষ হয়ে গেলেও `vault/02-STATE.md` আর `vault/06-PLAN.md` দেখে নতুন চ্যাট থেকে ঠিক পরের স্টেপ শুরু করা যায়।
